# FFXIV TTRPG Rulebook Compendia 繁體中文翻譯

本模組透過 [Babele](https://foundryvtt.com/packages/babele)，為 FFXIV TTRPG Rulebook Compendia 提供繁體中文翻譯，術語參考《Final Fantasy XIV》官方中文譯名。

## 相依需求

請在 Foundry VTT 中安裝並啟用：

- **FFXIV 系統**
- **Babele**
- **FFXIV TTRPG Rulebook Compendia** 核心合集模組

本模組僅提供翻譯，不包含核心合集內容。

## 安裝與啟用

1. 將本模組安裝至 Foundry VTT 的 `Data/modules` 資料夾。
2. 啟動或重新啟動 Foundry VTT。
3. 開啟或建立世界，確認上述相依模組皆已啟用。
4. 開啟 FFXIV TTRPG Rulebook Compendia 的合集，即可查看翻譯內容。

## 翻譯內容

目前包含以下合集的繁體中文翻譯：

- 工作與職業技能、特性
- 道具
- 日誌條目
- 巨集
- 稱號
- 隨機表
- 寵物與夥伴
- 部分 Stormblood（STB）相關工作、道具與寵物合集

翻譯內容會隨模組版本更新；核心合集新增或修改的項目，可能尚未有對應翻譯。

## 疑難排解

- **合集沒有顯示翻譯：** 確認 Babele、FFXIV 系統、核心合集模組及本翻譯模組均已啟用，並確認 Foundry 語言為 `zh-TW`。
- **部分項目仍是英文：** 該項目可能尚未翻譯，或核心合集更新後翻譯尚未同步。
